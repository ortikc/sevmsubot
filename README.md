# Расписание МГУ Севастополь — Telegram Mini App (MVP)

Бот: [@sevmsubot](https://t.me/sevmsubot). Кнопка «Расписание» в меню бота открывает приложение по адресу https://sevstud.site.

## Сервер

Приложение и бот работают на облачном сервере Timeweb (Россия), домен sevstud.site:

- код в `/opt/msu` (принадлежит root), данные в `/opt/msu/data` (пользователь `msu`), окружение Python в `/opt/msu/venv`;
- служба `msu.service` (systemd) запускает `run.py` и перезапускает его при сбое; в `/opt/msu/.env` — `BOT_TOKEN`, `WEBAPP_URL=https://sevstud.site` и `PORT=8090`, без `DEV_AUTH`. Раз `WEBAPP_URL` задан, туннель не поднимается;
- nginx (`/etc/nginx/sites-available/msu`) принимает домен и передаёт запросы на `127.0.0.1:8090`; сертификат Let's Encrypt продлевает certbot сам;
- логи: `journalctl -u msu -f`; обновить код: залить изменённые файлы в `/opt/msu` и `systemctl restart msu`.

Бот с одним токеном может работать только в одном месте. Пока он на сервере, на компьютере `BOT_TOKEN` в `.env` закомментирован: иначе две копии делили бы сообщения и слали напоминания дважды.

## Запуск на компьютере (для разработки)

```bash
pip install -r requirements.txt
python run.py
```

`run.py` поднимает сервер на `localhost:8080` и временный HTTPS-туннель: cloudflared из `bin/`, если он там есть, иначе localhost.run через ssh (`--ssh` выбирает его принудительно).
Адрес туннеля сам попадает в кнопку меню бота. Пока скрипт работает, приложение открывается из Telegram.

На Windows можно просто дважды кликнуть `start-server.cmd`: сервер и туннель запустятся отдельным процессом в фоне (логи в `data\server.log` и `data\server.err.log`). Если Cloudflare трижды подряд не выдаёт временный туннель, `run.py` сам переходит на localhost.run.

Без Telegram, в обычном браузере, с тестовым студентом:

```bash
python run.py --local
```

и откройте http://localhost:8080. Для проверки других моментов дня добавьте `?now=2026-10-21T13:20`.

## Как устроено

- `app/scraper.py` — забирает направления, курсы, группы и пары с raspisanie.sev.msu.ru (форма факультет → курс → группа). Запрашивает всегда с понедельника текущей недели на 5 недель вперёд (`dateStart`), поэтому прошедшие дни недели остаются в базе; уроки прошлой недели удаляются целиком, когда начинается новая. Полное обновление раз в 6 часов; расписание открытой группы освежается, если ему больше 2 часов.
- `app/db.py` — SQLite (`data/msu.sqlite3`): факультеты, группы, пары, пользователи.
- `app/auth.py` — проверка подписи `initData` от Telegram. Аккаунт = Telegram ID; имя, @username и аватар берутся из Telegram.
- `app/main.py` — API (`/api/me`, `/api/catalog`, `/api/profile`, `/api/schedule`, `/api/avatar`) и раздача `webapp/`.
- `app/bot.py` — на `/start` бот присылает кнопку открытия приложения. Он же присылает напоминания (ручные за 10 минут из шторки пары и автоматические о каждой паре за 5/10/15 минут) и утреннюю сводку в выбранное время. Сообщения со смайликами; Telegram Premium-эмодзи владелец бота (@ortikc, переменная `BOT_OWNER`) задаёт командой `/emoji` с пятью премиум-эмодзи по порядку: напоминание, утро, время, аудитория, пара. Они сохраняются в `data/emoji.json`; если Telegram их не примет, уйдут обычные.
- Настройки (`/api/settings`): напоминания, утренняя сводка, ссылка-подписка на календарь `/cal/<секрет>.ics` (Google/Apple Календарь). `/api/refresh` обновляет расписание группы с сайта сразу.
- `webapp/` — сам Mini App на чистом HTML/CSS/JS.
- Студклубы (`/api/clubs…`, таблицы `clubs`, `club_members`, `club_invites`, `club_posts`): состоять можно в любом числе клубов, своих (где ты владелец) не больше трёх (`CLUB_OWN_MAX`), в том числе при передаче прав. Клуб открытый, для друзей владельца или по приглашениям. Роли: владелец (назначает админов, передаёт права, удаляет клуб, только пока он в нём один), админ (настройки, приглашения, исключение обычных участников), участник. Ссылку на чат в Telegram видят только участники, кнопкой. Любой участник открывает карточку другого: заявка в друзья и «Написать в Telegram»; сам тег на страницах клуба не передаётся, ссылку `t.me/…` сервер отдаёт только участнику того же клуба (`/api/clubs/<id>/members/<id>/contact`).
- Лента клуба (`/api/clubs/<id>/posts`): записи пишут владелец и админы — текст до 2000 символов, фото или и то и другое; читают только участники. Фото хранятся в `data/posts` под случайными именами, которые получают только участники; удалить запись могут автор, владелец и админы. Все участники ставят реакции (одна на запись, набор `REACTIONS`: 👍 ❤️ 😂 😮 😢 🔥) и пишут комментарии в шторке (`/posts/<id>/reaction`, `/posts/<id>/comments`); запись можно опубликовать с выключенными комментариями (`comments_off`). Кто может открыть клуб (открытый, для друзей владельца, или приглашённый), тот видит его участников и записи, отмеченные «Видна всем» (`public`, по умолчанию выключено), и читает комментарии к ним; реакции, комментарии, чат клуба и «Написать в Telegram» остаются участникам. Вкладка «Общая лента» в разделе клубов (`/api/feed`) собирает открытые записи всех клубов, которые человеку можно открыть, с названием клуба над каждой. Записи «Видна всем» проходят простой фильтр мата (`app/profanity.py`: корни слов, латиница-двойники, точки и растянутые буквы); с матом такая запись не публикуется, а записи только для участников не проверяются. Старые открытые записи, которые фильтр не пропустил бы, при запуске сервера становятся записями только для участников (ничего не удаляется).
- Группа человека — цветной тег рядом с именем в списке участников клуба, в комментариях и в своём профиле; цвет вычисляется из названия группы (`groupHue` в `webapp/app.js`), поэтому у каждой группы он свой и всегда один и тот же.
- Клуб «По заявкам» (`visibility = closed`): виден всем, вступают по заявке (`/api/clubs/<id>/request`), которую принимают или отклоняют владелец и админы во вкладке «Участники» (`/requests/<tg_id>`).
- Уведомления (`notifications`, `/api/notifications`): колокольчик с красным счётчиком на главном экране рядом с переключателем расписания. Пишутся при заявке в друзья и её принятии, огоньке друга, приглашении в клуб, заявке на вступление и её принятии, новой записи в ваших клубах, комментарии к вашей записи, назначении админом, передаче клуба и исключении. Хранятся последние 100 на человека; открытие списка отмечает всё прочитанным.
- «О себе» (`/api/profile/bio`, до 200 символов): видят друзья и участники клуба.
- Клубы человека видны его друзьям во вкладке «Друзья» и в карточке друга, только если он сам включил «Показывать мои клубы друзьям» в настройках (`users.show_club`, по умолчанию выключено).

- Приложение на телефоне (PWA): тот же сайт можно поставить на главный экран (`webapp/manifest.webmanifest`, иконки в `webapp/icons/`), и тогда расписание, статистика и друзья открываются без интернета. Внутри Telegram это невозможно: Telegram без сети не открывает мини-приложение. Вне Telegram нет его подписи, поэтому вход идёт через бота: приложение берёт код (`/api/login/start`), студент открывает `t.me/sevmsubot?start=login_<код>` и жмёт «Да, это я» под предупреждением о чужих ссылках, а приложение меняет код и секрет, который не покидал устройство, на собственный ключ (`/api/login/claim`, заголовок `Authorization: Bearer`). В базе хранится только sha256 ключа (`devices`), устройство без заходов полгода выходит само. Из Telegram пункт «Установить на телефон» открывает сайт в браузере уже с входом (`/api/devices/handoff`, код в `#login=…`, одноразовый, 10 минут). Список устройств и выход — в настройках («Устройства»). Офлайн держит `webapp/sw.js`: оболочка приложения из сохранённой копии, ответы API приложения с ключом — сеть, а без неё сохранённый ответ с пометкой `X-Saved-At` (тогда внизу плашка «Нет сети · данные от …», а запись — реакции, заявки, настройки — не отправляется). Ответы с подписью Telegram не сохраняются: на одном телефоне бывает несколько аккаунтов. Версию воркера сервер ставит сам по состоянию файлов `webapp/`, так что после выкладки браузеры подтягивают новые файлы при следующем открытии. Установку предлагает бот: сразу после регистрации (и один раз тем, кто зарегистрировался раньше, при следующем открытии приложения — `/api/app-offer`) он присылает сообщение с кнопками «Скачать» и «Нет, не надо» (`users.app_offer`: sent, declined, opened, installed; у кого уже есть устройство, тому не присылает). «Скачать» — ссылка `/install/<токен>` (таблица `install_links`, в базе только sha256 токена, работает один раз и сутки): она входит в аккаунт тем же способом, что «Открыть в браузере», и после неё кнопки из сообщения убираются. «Нет, не надо» отвечает, что ссылку можно попросить командой `/app`. В браузере телефона — пошаговая инструкция под этот браузер со стрелкой к его кнопке («•••» в Safari, ⋮ в Chrome; в Chrome вместо шагов кнопка «Установить приложение»). Если ссылка из Telegram открылась во встроенном браузере другого приложения, вход по ней не тратится: страница просит открыть её в Safari или Chrome. Ключ дублируется в cookie `msu_device`: iPhone переносит в приложение на экране «Домой» cookie, а не хранилище. Исходник видеогайдов по установке — `video/install-guide.html` (`?p=ios` / `?p=android`, кадры снимаются через `window.seek(t)` и склеиваются ffmpeg). При обычном `python run.py --local` на localhost воркер не регистрируется, чтобы правки были видны сразу; проверять приложение на телефоне можно по адресу вроде http://msu.localhost:8080, там тестового входа нет.

- Неделя в чате с ботом: каждому, у кого выбрана группа, бот присылает и закрепляет одно сообщение с парами на текущую неделю (в воскресенье — на следующую). Раз в 10 минут сервер сверяет его с расписанием и правит то же сообщение, если что-то поменялось. Telegram хранит чат на телефоне, поэтому расписание видно и без интернета. Выключается в настройках («Неделя в чате с ботом»); команда `/week` присылает и закрепляет его заново.

- Персональные данные: на последнем шаге регистрации галочка «Даю согласие на обработку моих данных и принимаю политику конфиденциальности»; подчёркнутые слова открывают документы в нижней панели (`webapp/consent.html`, `webapp/privacy.html`, они же по адресам `/consent` и `/privacy` — ссылку `/privacy` можно указать в @BotFather). До галочки о новом человеке ничего не записывается, остальные API отвечают 403, а людей без согласия не видят другие и им не пишет бот. Те, кто зарегистрировался раньше, подтверждают согласие один раз в панели «Обновили правила». «Удалить аккаунт» в настройках (`DELETE /api/account`) стирает всё о человеке; владельцу клуба с участниками сначала нужно передать права. Если меняется текст документов, поднимите `CONSENT_VERSION` в `app/main.py`: согласие спросят заново.

## Бэкапы базы

Раз в сутки (по московской дате, при первом запуске сервера в этот день) сервер делает копию базы в `data/backups/msu-ГГГГ-ММ-ДД.sqlite3` встроенным механизмом SQLite, не останавливаясь, проверяет копию (`integrity_check`) и хранит последние 14. Фото (`data/avatars`, `data/posts`) в копию не входят.

Восстановить: остановить сервер, удалить `data/msu.sqlite3-wal` и `data/msu.sqlite3-shm`, скопировать нужную копию на место `data/msu.sqlite3` и запустить сервер.

## Ограничения MVP

- При запуске на компьютере адрес бесплатного туннеля меняется при перезапуске, вместе с ним меняется и ссылка на календарь; бот подхватывает новый сам. Если компьютер уснул или пропадал интернет, `run.py` замечает мёртвый адрес (3 неудачные проверки подряд, раз в минуту) и поднимает туннель заново. На сервере адрес постоянный.
- Токен бота лежит в `.env` (в git не попадает).
